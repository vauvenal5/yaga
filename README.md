## FAQ

### Why is this repository still empty?
Most of the work until now has been done in the [Nextcloud Neon fork](https://github.com/vauvenal5/neon) since it will be upstreamed. If you want to check out current development have a look at the [yaga-tag](https://github.com/vauvenal5/neon/tree/yaga) of my fork.

### Locking for the old Yaga app?
The repository was renamed to [Yaga-0.x](https://github.com/vauvenal5/yaga-0.x) and will not be maintained anymore.
