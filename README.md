## Welcome to the new Nextcloud Yaga app! 

This is a complete re-development of Yaga, based on the great [Nextcloud Neon](https://github.com/nextcloud/neon) framework.

## FAQ

### What is the expected timeline?
Expect an initial release during **October 2026**.

### Why is this repository still empty?
Most of the work until now has been done in the [Nextcloud Neon fork](https://github.com/vauvenal5/neon) since it will be upstreamed. If you want to check out current development have a look at [this](https://github.com/vauvenal5/neon/tree/rebase/20260818-yaga) branch.

## Locking for the old Yaga app?
The repository was renamed to [Yaga-0.x](https://github.com/vauvenal5/yaga-0.x) and will not be maintained anymore.
